Most Helmryth failures come from one of four layers: the desktop app, a local operator CLI, a connected service, or a workbench backend.

## Collect useful evidence

Before opening an issue, record:

- Helmryth version and operating system;
- selected engine and model;
- the exact visible error, not only “it failed”;
- whether the same operator CLI works directly in a terminal;
- whether restarting only the affected run changes the result.

Never post API keys, OAuth callback URLs, bearer tokens, or the contents of secure credential files.
