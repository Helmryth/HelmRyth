## How the pieces fit

| Layer | What it does | Where to configure it |
|---|---|---|
| **Operator** | Holds the identity, workstream, memory, and defaults | Operator settings |
| **Operator engine** | Runs the reasoning loop and capabilities | Model picker and System settings |
| **Work folder** | Gives the operator project context and a safe place to work | Operator settings |
| **Capabilities** | Authorizes services such as Gmail or GitHub | Capabilities |
| **Workbench** | Gives visual control of a desktop environment | Workbench panel |
| **Cadence** | Runs work later, on a schedule, or from a webhook | Cadences |
