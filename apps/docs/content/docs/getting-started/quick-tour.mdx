## 1. Sidebar

The sidebar holds your operators, crews, cadences, capabilities, profile, and system settings. Search looks through operator names and message history. Use **New or share** to create an operator or start a shared crew.

## 2. Workstream

Messages are the work log. Operator replies, questions, gate requests, capability progress, attachments, and failures stay together in the workstream. You can pin, copy, react to, search, and retry messages.

## 3. Run mode

The **Run** button starts a separate unit of work without losing the main workstream. A run keeps its own status and result, which is useful for parallel or delegated work.

## 4. Model picker

Pick an operator engine and model per operator. The picker separates cloud-backed CLIs from local engines and shows what is installed on this machine.

## 5. Workbench and trace

Open **Workbench** to choose where visual work runs. Open **Trace** to follow lower-level activity when a run is executing.

## 6. Capabilities and automations

Capabilities give operators authenticated access to services. Cadences turn a good direction into scheduled or webhook-triggered work.
