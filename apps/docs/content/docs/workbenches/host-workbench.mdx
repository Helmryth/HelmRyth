Host workbench control is off by default. The Electron main process owns the bundled CUA driver lifecycle so operating-system permissions are attributed to Helmryth rather than a background helper.

## macOS

The packaged app can request Accessibility and Screen Recording permission. After granting either permission, restart the control session when prompted so macOS applies the new grant.

## Ubuntu

Ubuntu 24.04 GNOME host control is temporarily disabled while the real-seat input-safety blocker in issue #345 is resolved. Packaged builds retain the pinned runtime for reproducible review, but Helmryth does not start it and clears legacy opt-ins. Workstreams, screen preview, remote workbenches, and isolated workbenches remain available. Do not start the bundled driver manually as a workaround.

## Safety model

- Enabling host control globally does not assign it to an operator.
- Choose **Host Workbench** for each operator that should receive the capability.
- Risky actions still surface through the gate flow.
- Missing permissions, unexpected binaries, unsupported desktop sessions, and failed health checks fail closed.
