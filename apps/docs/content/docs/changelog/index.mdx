## 0.1.0 — August 23, 2026

- Base Helmryth release with the desktop shell, harness, companion client, and local operator workstreams.
- Live engine discovery, capability routing, Workbench control, mobile pairing, and release packaging for the initial distribution lanes.
- Operator-facing memory, search, costs, and provenance plumbing with the current Helmryth vocabulary.
